# Module NextFTC Pedro

Pedro Pathing integration for NextFTC. Wraps the Pedro `Follower` so it can be driven from NextFTC's command-based framework and hooks into the robot lifecycle.

# Package dev.nextftc.v2.pedro

Core Pedro integration, including the `Pedro` entry point and the `PedroHook` that ties the follower into the OpMode lifecycle.

# Package dev.nextftc.v2.pedro.constants

Drivetrain constants and configuration for building a Pedro `Follower` from NextFTC hardware, such as `NextMecanum`.
