ForceUnit

class ForceUnit(baseUnit: ForceUnit?, toBaseConverter: (Double) -> Double, fromBaseConverter: (Double) -> Double, unitName: String, unitSymbol: String) : Unit<ForceUnit> (source)

Unit of measurement for force.

Supported units include newtons (base unit), kilonewtons, pounds-force, and kilograms-force. Force is dimensionally equivalent to mass × acceleration = mass × distance / time².
