WPILogWriter

class WPILogWriter @JvmOverloads constructor(output: OutputStream, extraHeader: String = "", timeSource: TimeSource.WithComparableMarks = TimeSource.Monotonic, val origin: ComparableTimeMark = timeSource.markNow()) : Closeable, Flushable(source)

Writes the WPILOG format, version 1.0, to output.

Start an entry with startEntry (or startStructEntry), then append values to the id it returns. Every timestamp is in microseconds since origin, as measured by timeSource. Get one from now or timestampOf, or compute your own on the same basis.

All methods are safe to call from multiple threads. Each call writes one whole record, so records from different threads interleave but never tear. The writer adds a buffer in front of output unless it is already a BufferedOutputStream, so call flush to force pending records out.

Parameters

output

Where the log goes. close closes it.

extraHeader

A string stored in the file header, conventionally JSON. Readers ignore it.

timeSource

The clock that timestamps are measured on. A log created on its own can use the default. To line a log up with a dev.nextftc.telemetry.nt.NT4Server or another writer, give them the same source and the same origin.

origin

The moment timestamp zero refers to, a mark from timeSource. The default is the moment the writer is created. Share one origin between sinks that should agree on every timestamp.

Throws

IllegalArgumentException

if origin isn't from timeSource, or is in the future
