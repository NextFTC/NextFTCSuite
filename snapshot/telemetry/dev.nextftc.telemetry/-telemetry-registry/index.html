TelemetryRegistry

class TelemetryRegistry @JvmOverloads constructor(val timeSource: TimeSource.WithComparableMarks = TimeSource.Monotonic, val origin: ComparableTimeMark = timeSource.markNow())(source)

The set of TelemetryBackends that logged values are routed to, plus the clock that stamps them.

Most code uses Telemetry, which wraps one shared registry. This is a class so a test can build its own with a kotlin.time.TestTimeSource and a mock backend without affecting anything else.

Timestamps

Every value is stamped in microseconds since origin, as measured by timeSource. Give the same source and origin to a log writer and a server and they agree with this registry on every timestamp.

Backends

A registered backend receives every value, or only the values whose path is under the prefixes it was registered with. Backends can change while other threads are logging. Handles notice the change on their next value and ask the new set of backends for their entries.

Warnings

Telemetry reports a wrong type, a value it can't log, or a backend that threw through warningHandler, then carries on, so a bad value can't crash an OpMode. Each distinct message is reported once, so a bad value logged every loop doesn't flood the output.
