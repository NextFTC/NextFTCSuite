fun log(name: String, value: Any)(source)

Logs value at name, choosing how from what it is.

Numbers, booleans, strings, and primitive arrays go to the topics above, with a Byte or Short logged as an integer. An array of objects is logged as an array of structs, or of strings. A value with a TelemetryTypeHandler registered for its type, such as a Measure, is logged by that handler. A TelemetryLoggable is logged into the child table name. Anything else is logged as a struct.

A collection or map is rejected with a warning, because its element type is erased. Use arrayTopic or logArray for a list.
