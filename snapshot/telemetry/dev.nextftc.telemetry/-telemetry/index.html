Telemetry

object Telemetry(source)

The entry point for telemetry: a shared TelemetryRegistry and its root table.

Telemetry.log("Battery/Voltage", voltageSensor.voltage)

val drive = Telemetry.table("Drive")
val velocity = drive.doubleTopic("leftVelocity")
velocity.set(left.velocity)
drive.log("pose", follower.pose)
Content copied to clipboard

Values go to the backends registered on registry. On a robot, NextFTC registers them for each OpMode. In a unit test, register a dev.nextftc.telemetry.backend.MockTelemetryBackend and read back what was logged, or build a TelemetryRegistry of your own.

Everything here forwards to the root table. See TelemetryTable for how values are typed, what a name holds, and what thread safety to expect.
