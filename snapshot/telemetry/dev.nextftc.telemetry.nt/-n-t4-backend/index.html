NT4Backend

class NT4Backend @JvmOverloads constructor(val server: NT4Server, stopServerOnClose: Boolean = false) : TelemetryBackend(source)

Publishes logged values to an NT4Server, one topic per path.

A topic is published when its path first gets a value, so dashboards only see topics that have data. Closing the backend removes the topics it published, which is how an OpMode's topics go away when it ends. The next OpMode can publish the same names again, but not with different types: the server remembers each name's type for as long as it exists, because dashboards keep a field's first type. Publishing a name with another type is reported as a warning and its values aren't sent.

The server is not started or stopped for you unless stopServerOnClose is set, because a server normally outlives any one backend. Values go out with the timestamp the registry gave them, so for clients to read them correctly the server and the registry must share a time source and origin.

After the backend is closed, its entries drop values quietly.
