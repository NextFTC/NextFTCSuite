StructSchema

interface StructSchema<T>(source)

Describes a WPILib struct: a fixed-size, packed, little-endian binary encoding of T together with a text schema that tells readers how to decode it.

This mirrors the shape of WPILib's Struct<T> interface, so a type that already has a WPILib struct can be adapted by forwarding its members. A struct is logged as a raw value whose type string is typeString, plus one schema entry per type (see schemaTopicName) holding schema.

AdvantageScope recognizes WPILib's built-in types such as Pose2d by typeName, so a schema meant to be drawn on a field view must use the same name and field layout as WPILib's.
