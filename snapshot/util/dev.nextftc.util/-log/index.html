NextFTC Util/dev.nextftc.util/Log

Log

object Log(source)

A logging facade for code that can't depend on the FTC SDK.

Messages go to sink. The default prints warnings and errors to standard error, which is what you want in unit tests; hardware's RobotController installs one that writes to the Robot Controller log.
