CoroutineCommandBuilder

class CoroutineCommandBuilder : Command

Builds a CoroutineCommand, in the same fluent style as com.pedropathing.ivy.CommandBuilder.

The builder is itself a com.pedropathing.ivy.Command, so it can be scheduled or composed with the usual Ivy operators without calling build:

coroutineCommand {
  await(arm.toHigh())
  wait(0.5)
  fork(claw.open())
}.requiring(arm).setPriority(1).schedule()
Content copied to clipboard

A fresh CoroutineCommand is created from the current configuration every time the builder is started, so one builder can be scheduled repeatedly.
