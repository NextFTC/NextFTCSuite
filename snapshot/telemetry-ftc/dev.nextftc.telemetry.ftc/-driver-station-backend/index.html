DriverStationBackend

class DriverStationBackend(telemetry: Telemetry) : TelemetryBackend

Shows logged values on the Driver Station, one line per path, using an FTC SDK SdkTelemetry.

Each path gets a retained line, captioned with the path and updated in place, so the lines survive the SDK's auto-clear and don't disturb ones the OpMode adds itself. Logging never calls SdkTelemetry.update, so a value reaches the Driver Station on the next update. The SDK calls it after every loop of an iterative OpMode, but not for a LinearOpMode, which has to call telemetry.update() itself or FtcTelemetry.update. Until then, the Driver Station shows the previous values.

Values are shown as text. A unit property is added after the value, and a struct or an array is shown with its toString or contents. The Driver Station has limited room, so register this with path prefixes if the log is large.

After the backend is closed, its lines are removed and its entries drop values quietly.
