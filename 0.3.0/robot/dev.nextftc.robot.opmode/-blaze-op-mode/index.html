BlazeOpMode

abstract class BlazeOpMode(robot: NextRobot, hooks: OpModeHook) : NextOpMode

Base class for NextFTC OpModes that run with Blaze enabled.

Extending this class instead of NextOpMode routes motor writes through Blaze for the whole OpMode and exposes callbacks for data Blaze provides.
